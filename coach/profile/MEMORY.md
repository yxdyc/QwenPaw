## 这是公共模板，不是用户记忆

本文件会被 Git 跟踪，只定义可复用的记忆规则。不要在这里写用户名、
公司/项目代号、真实主机、IP、文件路径、账号、token、持仓或其他个人资料。

运行时记忆应写入以下 Git 忽略目录：

- `.local/memory/`：长期记忆
- `.local/profile/learner.json`：学习档案
- `.local/projects/`：用户明确提供的项目上下文
- `.local/logs/`：学习会话记录

## 写入规则

- 只保存完成学习服务所必需的信息，并优先保存摘要而非原始内容。
- 对推断信息和敏感信息，先展示拟写入内容并征得用户确认。
- 不保存密钥、口令、完整认证材料；只记录“凭据已在安全存储中配置”。
- 用户要求删除或更正时，更新私有状态并在会话中确认结果。
