# nano-opd L2 — multi-teacher OPD：加号写在哪，以及什么时候听谁的

> **模块定位**：L0/L1 证明了单教师 OPD 的核心算术——reverse KL 的期望在学生
> 分布下，所以学生必须自采样、教师只打分。L2 引入**第二个教师**，问生产配方
> 真正遇到的问题：**两个教师的知识怎么合进一个学生？** 答案分两类设计面：
> 融合位置（fuse-then-distill：概率级 / logit 级 / loss 级混合）与路由
> （distill-then-route：按上下文选教师 / 按学生输出选教师）。五个配方在同一
> on-policy 循环里只换教师信号的组合方式，跑出四种结局——塌缩、瘫痪、锁一模、
> 双域全学会——每一种都有数学签名。
>
> **K+1 起点（K = L1）**：知道「学生写、教师批」的接口、2×2 因子设计、背书度
> 指标。本节推进到 K+1：教师从一个变两个时，「批」这个动作本身出了新问题——
> 两个教师的意见怎么合并？这不是工程细节，是目标函数层面的选择。
>
> **机制类别声明**：多教师 OPD 的单源变体很多。本节只教 survey
> `[2604.00626]` taxonomy 里的**机制类别**（融合
> 位置 ×2 + 路由 ×2），不追个别方法名；MOPD `[2606.30406]` / MiMo-V2-Flash
> `[2601.02780]` 只作为「生产确实这样做」的数据点出现。
>
> **反幻觉声明**：本文件无 mock——教师/学生的前向/反向/采样全部是真实 torch
> 计算。但「立场教师」（在自己领域近确定性、在对方领域自信地错）是刻意的
> 机制放大设置，不是对生产教师的写实；全部数字为现场实跑（CPU，固定 seed），
> 不是任何真实模型的 benchmark。

## 2. 任务：把 L1 的双语密码本领域化

L1 的任务是「4 位数字 → 小写密码本 A **或** 大写密码本 B 都算对」，一个双语
教师同时会两套。L2 把同一个任务**领域化**：prompt 里加一个领域标记，
`<in> 3 1 4 1 <a> <out>` 只有 codebook A 正确，`<in> 3 1 4 1 <b> <out>` 只有
codebook B 正确。词表从 66 涨到 68（加 `<a>`/`<b>`），响应长仍是 9
（8 字母 + `<end>`）。

然后是两位**立场教师**（`train_fundamentalist`）：教师 A 在**任何上下文**
（包括领域 B 的 prompt）都坚持 codebook A，教师 B 镜像。2×2 背书表把冲突
推到极端：

```text
教师A:  领域A gold -0.001   领域B gold -8.570
教师B:  领域A gold -8.374   领域B gold -0.001
```

对角线 −0.001 nats/token ≈ 近确定性（教师对自己领域的 gold 几乎给满概率），
非对角线 −8.5 量级 = 在对方领域**自信地错**——不是随机（随机是 −ln 68 ≈
−4.2），而是确定性地给错答案背书。

**为什么刻意这么极端**：真实领域教师（代码教师面对数学题）的域外行为介于
随机与自信地错之间。本节把冲突推到极限，让融合失败模式的机制裸露出来
（§11 讨论边界）。断言 `tab["A"]["A"] − tab["A"]["B"] > 1.0` 保证教师确实
能区分领域，这是后面全部实验的前提。

## 3. 为什么问这个问题：多教师是生产真实问题

单教师 OPD 的算术（L0/L1）回答「学生为什么要自己写」。一旦进入生产，问题
立刻变成「多个教师的知识怎么进一个学生」：

- OPD survey `[2604.00626]` 把 OPD 形式化为**学生自采样轨迹上的
  f-divergence 最小化**，其 taxonomy 的多教师分支正是「融合 vs 路由」；
  survey 正文并转述 DeepSeek-V4 采用 pure multi-teacher OPD
  `[TODO: verify——本报告未直接核验 DeepSeek-V4 技术报告，口径承 L0 §15]`。
- 生产数据点（§八 C 层纪律：只作机制类别的存在性证据，不展开方法名）：
  MOPD `[2606.30406]`（多教师 OPD 做能力整合）、MiMo-V2-Flash
  `[2601.02780]`（per-domain teachers + 学生自采样蒸馏）、Qwen3
  `[2505.09388]`（生产配方采用 OPD）。

设计空间沿一个轴切开：**加号写在哪？**

| 设计面 | 配方 | 教师信号的组合发生在 |
|--------|------|----------------------|
| fuse-then-distill | `mix_prob` | 概率空间：p_mix = ½(p_A + p_B)，再对 p_mix 做 OPD |
| fuse-then-distill | `mix_poe` | logit 空间：p_mix ∝ √(p_A·p_B)（product-of-experts），再 OPD |
| fuse-then-distill | `loss_mix` | loss 级：L = ½KL(q‖p_A) + ½KL(q‖p_B) |
| distill-then-route | `route` | 不合并——按 prompt 领域标记选教师（context routing） |
| distill-then-route | `route_self` | 不合并——按学生响应的首 token 选教师（output routing） |

五个配方共用**同一个 on-policy 循环**（`train_multi_opd`）：学生自采样 →
两个教师都打分 → 按 recipe 组合教师信号 → token 级 reverse KL 反传。
唯一变量是「加号的位置」——这是因子设计思想的延续（L1 §3）。

## 4. 加号写在哪：一个恒等式与一个可测间隙

先看三个融合变体之间的数学关系。输出 `[2]` 的探针**不需要训练**
（初始化学生 + teacher-forced 序列），验证三条数学事实。

### 4.1 恒等式：loss 级混合 ≡ 对未归一化几何混合的 reverse KL

逐项展开（q 是学生 token 分布，p_A、p_B 是教师）：

```text
½KL(q‖p_A) + ½KL(q‖p_B)
= E_q[log q − ½log p_A − ½log p_B]
= E_q[log q − log √(p_A·p_B)]
= KL(q ‖ √(p_A·p_B))          ← 目标未归一化
```

实测逐 token 最大绝对差 **9.54e-07**——float32 机器精度，恒等式成立。
含义：**「在哪写加号」不决定目标函数，数学决定**。loss 级加权和与 logit
空间几何混合是同一个优化目标的两种写法。

一个推论（self-check (c) 的依据）：归一化常数对学生参数没有梯度。
mix_poe 的目标是 KL(q ‖ √(p_A·p_B)/Z)，比 loss_mix 只差一个 log Z——
Z 只依赖冻结的教师输出，∂log Z/∂θ = 0，所以两者的**梯度场解析上完全
相同**。实测终态 mix_poe vs loss_mix = 0.010/0.011 vs 0.011/0.011
（valid_A/valid_B）：差异来自两条计算图（logsumexp 归一化 vs 直接相加）
的 float32 舍入在 900 步训练中的放大，不是机制差异——所以断言只要求
|Δ| ≤ 0.02，不要求逐位相等（§6）。

### 4.2 Jensen 间隙：教师分歧是逐位置可测的量

算术混合 ½(p_A+p_B) 与几何混合 √(p_A·p_B) 之间隔着一个 Jensen 间隙：

```text
gap = loss_mix − KL(q ‖ ½(p_A+p_B))
    = E_q[log(½p_A + ½p_B) − ½log p_A − ½log p_B]
    = E_q[log Σ_w p_w − Σ_w log p_w]  ≥ 0   （log 凹性）
```

等号当且仅当 p_A = p_B（两教师一致）。注意期望写在 **q（学生自己的样本）**
下面——这个量测的是「**教师对学生自己写出来的东西的分歧度**」，逐 token
可测，不需要任何训练：

```text
最小值 = 1.54e-01（应 ≥ 0，log 凹性）
字母位均值 = 1.048 nats/token（教师冲突）
<end>位均值 = 0.203 nats/token（教师一致）
```

分歧集中在 8 个字母位（内容位），`<end>` 位小但不为零——域外教师看到
对方领域的 gold 前缀时即使在结构位也 off-manifold（分布弥散），残留
0.203 的间隙。这个量后面会再出场：它是判断「融合是否可行」的先验探针
（思考题 1）。

## 5. 三种失败签名：塌缩、瘫痪、与 ½ 票

`[3]` 的表是全文的核心证据。先读三个融合配方的失败——它们**失败的方式
各不相同**，各有数学签名：

```text
recipe      valid_A  valid_B   total  frac_A  lock     背书A     背书B
mix_prob      0.006    0.004   0.005   0.590  0.18  -4.952  -4.895
mix_poe       0.010    0.011   0.011   0.494  0.01  -5.270  -5.062
loss_mix      0.011    0.011   0.011   0.500  0.00  -5.266  -5.057
```

### 5.1 mix_poe / loss_mix：塌缩——序列模式从目标里消失了

token 级独立混合意味着：目标分布里一条完整序列的概率 = 逐 token 边缘
概率的乘积。每个字母位上两个教师的候选各得 ≈½ 的边缘质量，所以任何
一条 gold 序列（8 个字母全对）的目标概率 ≈ (½)^8 = 0.0039 量级。
精确匹配率实测 0.011——同量级。**序列层面的模式（「8 个字母必须同属
一个 codebook」这个相关性）在目标函数里根本不存在**，学生想学也没得学。

`[4]` 的样本是塌缩的直观形态：`5216 <a> -> rmyGGQD<in>`——前 3 个字母
碰巧是 A 密码本的小写，随后大写入侵，最后吐出 `<in>`。每个位置独立掷
硬币，序列没有一致性。

### 5.2 mix_prob：瘫痪——模式在目标里，但 on-policy 采样找不到

算术混合 ½(p_A+p_B) 与几何混合的本质区别：**算术混合保留两个序列模式**
——纯 A 序列和纯 B 序列各有 ≈½ 的序列级质量，目标函数里两个模式都在。
那学生为什么学不会？因为 on-policy 的梯度只能看到学生**自己采出来的**
样本。看 `½ 票` 探针（构造性杂交样本 = 大小写交替，两教师各认一半字母位）：

```text
位置0 = -0.694 nats/token（预测 −ln 2 = -0.693，两教师都在流形上）
deeper = -2.528 nats/token（杂交前缀使两教师同时 off-manifold）
```

位置 0 的前缀还是 prompt——两个教师都在流形上，各自把 ≈1 的质量投给
自己的候选，算术混合给每个候选恰 **½ 票**：logprob ≈ ln ½ = −ln 2 =
−0.693（实测 −0.694）。一旦学生开始杂交（位置 0 之后前缀已是大小写
混杂），两个教师**同时** off-manifold，票衰减到 −2.528。

于是动力学锁死在一个对称的平衡点上：学生初始采样是逐字母掷硬币（每个
字母位两个候选各 ≈½ 票）→ 采出来的全是杂交序列 → 杂交前缀下混合目标
的条件分布**仍然逐位置近似对称**（两个教师都懵，各自仍弱地偏向自己的
大小写）→ 学生的最优响应 = 继续匹配 token 级边缘 → 纯模式前缀在学生
自己的分布下概率 ≈ (½)^8 ≈ 0.004，**模式发现的正信号指数级稀有**。
结局：token 级边缘匹配的**杂交平衡**——valid 0.005、frac_A 0.590、
lock 0.18（轻微对称破缺，但不是锁模）、背书 −4.95（两个教师都不认账）。

这是 L0「锁模是算术定理」的序列空间版：L0 的模在单 token 采样可达，
reverse KL 立刻选边；L2 的模需要 8 个字母的相关性，**on-policy 采样
本身成了瓶颈**。这正是生产 OPD 把采样吞吐当一等 infra 问题的原因
（→ [nano-slime](../nano-slime/) / [nano-vllm-sglang](../../03-data-distributed-rsi/nano-vllm-sglang/)）。

### 5.3 两种失败的区分为什么重要

塌缩（模式不在目标里）与瘫痪（模式在目标里但采样找不到）是**不同的病**：
前者换优化器、加步数都无效（目标函数里没有的东西学不出来）；后者理论上
换采样策略（比如显式注入纯模式前缀）可救，但标准 on-policy 循环救不了。
§11 的边界探针用实测排除了「瘫痪只是步数不够」的替代假设。

## 6. self-check 断言设计史：每一条断言一个理论锚

代码 `[5]` 的 self-check 不是「跑出来什么数就断言什么数」——那等于没有
断言。每一条都锚定一个独立推导的理论预测（承 L1 §11.2 的断言设计史传统）：

| 断言 | 理论锚 | 松弛带依据 |
|------|--------|-----------|
| (a) 恒等式 < 1e-5 | §4.1 代数恒等式 | float32 机器精度（实测 9.54e-07） |
| (a) Jensen gap_min > −1e-6 | log 凹性（§4.2） | 数值噪声带 |
| (a) gap_letters > 3×gap_end | 冲突在内容位、一致在结构位（任务构造） | 3 倍是保守分界（实测 1.048 vs 0.203 ≈ 5.2×） |
| (a) ½ 票 ±0.05 | ln ½ = −ln 2（§5.2 推导） | 教师非严格 one-hot 的泄漏带 |
| (b) poe/lm total < 0.05 | (½)^8 = 0.0039 量级（§5.1） | 留一个量级松弛（实测 0.011） |
| (c) \|poe−lm\| ≤ 0.02 | 归一化常数无梯度 → 同一梯度场（§4.1 推论） | float32 舍入经 900 步放大的实测幅度 |
| (d) mp total < 0.05 | 杂交平衡：token 级边缘匹配无序列模式（§5.2） | 与 (b) 同带，机制不同 |
| (e) route 双域 > 0.80 | 逐域退化为单教师 OPD（L1 已证 0.9+ 量级） | 容量差 22x 下的保守下限 |
| (f) route_self lock > 0.90 且单域 < 0.05 | 自确认回路：路由信号来自学生输出 → 正反馈锁模（§7.2） | 锁模是结构性的，带很窄 |

**设计原则**：断言断的是**机制预测**（数学事实 / 动力学结局的类别），
不是经验数值。数字换了 seed 会变，机制不变——所以 (d) 不断言
「frac_A = 0.590」，只断言「停在杂交平衡（total 趋零且 lock 不趋一）」。
这也让 (d) 能与 (f) 形成对照：同为「没学会两个领域」，杂交平衡
（lock 0.18）与自确认锁模（lock 1.00）是两种不同的失败，断言必须分得开。

## 7. 路由：唯一成功的配方，与它的自确认反例

### 7.1 route（context routing）：冲突在融合之前解决

```text
route         0.978    0.973   0.975   0.501  0.00  -0.032  -0.037
```

`route` 逐样本按 prompt 的领域标记选教师：领域 A 的样本只由教师 A 打分，
领域 B 只由教师 B。**加号根本不存在**——每条学生自采样样本退化为
L1 的单教师 OPD，两个领域各自独立地走通了 L0/L1 已经证明的机制。
背书 −0.032/−0.037 ≈ 0（教师完全认账），与 L1 单教师 OPD 的终态同量级。

这解释了生产形态：MiMo-V2-Flash `[2601.02780]` 的 per-domain teachers、
MOPD `[2606.30406]` 的按能力拆教师，本质都是 context routing——
**先按上下文决定听谁的，再让对应的教师做 OPD**。融合不是多教师 OPD
的必经之路；当领域可分时，路由严格更优（route 0.975 vs 最好的融合
0.011，断言 (e) 要求差 > 0.50）。

### 7.2 route_self（output routing）：路由信号来自学生自己 = 自确认回路

`route_self` 把路由信号换成**学生响应的首 token**：首字母小写 → 教师 A
批，大写 → 教师 B 批，非字母 → 退回算术混合。结果：

```text
route_self    0.000    0.986   0.493   0.000  1.00  -8.550  -0.018
```

本 seed 下学生初始采样把首 token 掷向了大写一侧 → 教师 B 批改 → 强化
大写 → 更多样本被路由给教师 B → …… **正反馈回路**把初始的采样噪声放大
成 lock = 1.00：领域 B 全学会（0.986），领域 A 被彻底牺牲（0.000，
背书 −8.550 ≈ 立场教师的非对角线水平——学生在领域 A 的 prompt 下写
大写，被教师 A 按「自信地错」打分）。锁在哪个域由初始采样噪声决定
（seed 依赖），**锁模本身是结构性的**——路由信号一旦来自学生输出，
教师的批改就变成了对学生既有偏向的确认，而不是纠正。

与 L0 的呼应：reverse KL「绝不骑墙」（L0 §8）——route_self 把选边权
交给了学生自己的第一次掷硬币，然后让教师信号去放大它。这是
**self-confirmation loop** 在蒸馏里的最小形态；同一个结构在 RL / RSI
语境下被刻意利用时就是自训练的正反馈（思考题 3）。

## 9. 费曼：能不能讲给外行听

**类比：一个学徒，两个倔师傅。** 小写师傅坚持一切用小写（哪怕工单要求
大写，他也自信地批小写），大写师傅镜像。学徒脑子小，两套都学。

- **把两个师傅的意见平均起来批改**（融合）：学徒每个笔画位置都得到
  「小写半票、大写半票」——怎么写都是半对，没有方向，最后写出大小写
  混杂的东西，两个师傅都不认账（mix_prob，背书 −4.95）。更糟的是
  logit 级 / loss 级平均（mix_poe / loss_mix）：连「整篇必须同一风格」
  这个要求都被平均掉了——每笔独立掷硬币，塌缩成乱码。
- **看工单领域标签决定交给谁批**（route）：小写工单交小写师傅，大写
  工单交大写师傅。冲突在批改之前解决，学徒两套都学会（0.978/0.973）。
- **看学徒自己第一笔决定交给谁批**（route_self）：第一笔碰巧小写 →
  小写师傅批 → 强化学徒写小写 → 大写师傅永远等不到活 → 一个领域被
  彻底牺牲（lock 1.00）。

**一句话版**：两个师傅打架时，把他们的意见平均起来教不出任何人；
看工单决定交给谁，能全学会；看学徒自己的第一笔选师傅，越错越深。

**类比边界**：真实教师冲突没有这么极端（立场教师是机制放大设置）；
真实领域标签不是 prompt 里现成的 `<a>`/`<b>`，生产的路由器本身是学出来
的模型（所以思考题 5 问路由器出错怎么办）；真实学生容量大到可能同时
装下两个领域——本节学生 4,980 参数 vs 教师 110,788×2，容量差是设置
的一部分。

## 10. 思考题

1. **互补教师**：如果两个教师不是冲突而是互补（数学教师只在数学域确定、
   代码教师只在代码域确定，域外接近随机），mix_prob 还会失败吗？用 §4.2
   的哪个探针量可以在训练前预测答案？（提示：Jensen 间隙 ≈ 0 意味着
   两教师在学生样本上几乎处处一致，融合与单教师无异。）
2. **归一化常数**：证明 KL(q ‖ r/Z) 与 KL(q ‖ r)（r 未归一化）对学生
   参数 θ 的梯度相同。若把 reverse KL 换成 forward KL（期望写在教师下），
   同样结论成立吗？采样需求（谁生成样本）会变吗？（联系 L0 的算术：
   期望写在哪，样本就从哪采——归一化不改变采样需求。）
3. **自确认回路的两副面孔**：route_self 的自确认在蒸馏里是失败模式，
   但同一个结构在 RL / RSI 里被刻意利用——举一个例子（提示：
   self-rewarding / 迭代自训练中「学生自己的输出被自己或同源模型
   打分再强化」）。什么时候正反馈是引擎，什么时候是陷阱？判据是什么？
4. **N 教师外推**：加入第三个立场教师 C（第三套密码本），loss_mix 的
   塌缩速度和 ½ 票探针的预测值分别变成什么？（提示：(⅓)^8 与 −ln 3；
   用 `OPD_L2_PROBE` 的思路设计一个最小验证。）
5. **路由器出错**：生产的路由器是学出来的模型。若路由准确率 90%，
   10% 的样本被错误的教师打分，后果更接近 L1 的哪个配方的偏差？
   （提示：错误教师的背书进入梯度 = 系统性偏差源，对照 L1 opd_off
   的「错误估计器」与 route 的「干净单教师信号」。）

## 11. 反例与边界

**toy 尺度诚实声明**：V=68、学生 4,980 参数、教师 110,788×2、封闭
密码本任务、CPU 40 秒级。全部数字只证明机制存在，**系数不可外推**到
真实模型（真实词表 32K–150K、真实教师冲突温和、真实领域边界模糊）。

**立场教师是刻意设置**：真实领域教师的域外行为介于随机（−ln V）与
自信地错之间；本节把冲突推到极端让失败模式可见。融合的失败边界由
Jensen 间隙的量级控制（思考题 1）——冲突温和时融合可以工作，这正是
「什么时候该路由、什么时候直接融合」的真实决策依据。

**边界探针实测（`OPD_L2_PROBE=1` 单独触发，不入主流程锚）**：
「mix_prob 的瘫痪只是步数不够吗？」——对算术混合目标训练 2400 步
（主预算 900 步的 2.7 倍）并加教师温度软化：

```text
--- probe: mix_prob T=1.0 steps=2400 lr=0.002 (eval m_per_prompt=8) ---
    step  600: valid_A=0.004 valid_B=0.003 lock=0.14
    step 1200: valid_A=0.008 valid_B=0.004 lock=0.33
    step 1800: valid_A=0.005 valid_B=0.007 lock=0.17
    step 2400: valid_A=0.005 valid_B=0.005 lock=0.00
--- probe: mix_prob T=3.0 steps=2400 lr=0.002 (eval m_per_prompt=8) ---
    step  600: valid_A=0.000 valid_B=0.000 lock=1.00
    step 1200: valid_A=0.000 valid_B=0.000 lock=1.00
    step 1800: valid_A=0.000 valid_B=0.000 lock=1.00
    step 2400: valid_A=0.000 valid_B=0.000 lock=1.00
```

固定 seed 的边界探针给出相同结局（复验方式见 §13）。T=1.0 加到
2400 步仍停在 ~0.005——**瘫痪不是耐心问题**；T=3.0 软化教师后 valid
掉到 0.000（目标更平、序列模式信号更弱）。注意 T=3.0 的 lock=1.00
**不是锁模**：valid 全零时 frac_A = 0/max(total,1e-9) = 0，lock =
|0−0.5|×2 = 1.00 是 total≈0 的退化伪影——`evaluate_domains` 的
docstring 明确警告该量只在 total 显著时可解读。这是一个现成的指标
有效性教训：**指标不能离开它的有效域解读**。

**真机边界**：真实模型的多教师 OPD 需要 rollout infra（学生自采样吞吐，
→ nano-slime / nano-vllm-sglang）与多教师前向的显存/调度成本，
本 toy 未覆盖这些成本，须在真实系统中另行验证。

**确定性声明**：固定 seed、CPU、`-B` 任意空 CWD 可跑；stdout 不写墙钟，
因此可以直接 `cmp`，无需掩码。
